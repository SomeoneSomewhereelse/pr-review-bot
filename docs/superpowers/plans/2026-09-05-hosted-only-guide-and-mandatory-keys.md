# Hosted-only guide, mandatory Render/UptimeRobot keys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the guide's Local setup track, make `RENDER_API_KEY`/`UPTIMEROBOT_API_KEY` mandatory instead of optional-with-SKIPPED-degradation, and simplify `doctor.py` accordingly — plus the README/ISSUES.md/env-example follow-on edits that ride along.

**Architecture:** No new modules. This trims existing conditional branches (`doctor.py`'s track fork, five `deploy.py` checks' SKIPPED-on-missing-key paths, `_prereqs.py`'s tunnel-tool branch) and moves/deletes/edits documentation files (guide, README, `mkdocs.yml`, ISSUES.md). Every code change is a deletion or a status-string flip (`SKIPPED` → `FAIL`), never new logic.

**Tech Stack:** Python 3.12, pytest, MkDocs (`mkdocs build --strict` in CI), the existing `bot.scripts.gen_docs` generator.

**Spec:** `docs/superpowers/specs/2026-09-05-hosted-only-guide-and-mandatory-keys-design.md`

## Global Constraints

- `DATABASE_URL`-gated checks (`database`, `provider`) keep their existing `SKIPPED`-without-key behavior — out of scope, do not touch.
- `set_override.py` and the ISSUES.md dashboard/deploy.py-overlap Design Gap are explicitly **not** being resolved — only documented as deferred (Task 6).
- Every task that touches `bot/` must leave `uv run ruff check .` and `uv run pytest -v` green before moving to the next task.
- Any hand-edit to `guide/reference/{config,pricing,checks,sync-env}.md` is forbidden — those are generated by `uv run python -m bot.scripts.gen_docs` and CI fails the build if they drift (`.github/workflows/ci.yml`'s `docs` job).
- `uv run mkdocs build --strict` must pass after any guide/`mkdocs.yml` change — CI runs this too.
